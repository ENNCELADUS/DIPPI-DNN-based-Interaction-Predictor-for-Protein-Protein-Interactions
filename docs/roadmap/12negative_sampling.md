# neg sampling 方法论

## 总体思路（一句话版）

> 在**只包含正样本蛋白的子图上**构建负样本，
> 用 **Degree Distribution Balanced (DDB)** 思路保持正负的度分布相似，
> 再按 **hub 与 2-hop 邻居**定义一部分 hard neg，
> 最后用 **1:1 pos:neg + 分层比例**构成你的 pretrain 批次。

这样既是学界目前比较推崇的“**度分布平衡负采样**”路线，又完全不依赖外部信息。

---

## 步骤 1：只在“正样本蛋白子集”里工作

### 1.1 构建正样本图

* 令正样本集合为 (E_{\text{pos}})：每个元素是一对互作蛋白 ((u,v))。
* 构建点集
  [
  V_{\text{pos}} = { p \mid p \text{ 出现在任意正样本对中} }
  ]
* 把 (G_{\text{pos}} = (V_{\text{pos}}, E_{\text{pos}})) 当成“**唯一信任的互作图**”。

> 之后所有的负样本都只在 (V_{\text{pos}}) 上采，不再利用那些“只在 neg 中出现的蛋白”。

### 1.2 丢弃“只出现在 neg 的冷门蛋白”

如果你当前有一个“原始负样本集” (E_{\text{neg,raw}})：

* 对每个 ((i,j)\in E_{\text{neg,raw}})：

  * 若 (i\notin V_{\text{pos}}) 或 (j\notin V_{\text{pos}})，直接丢弃；
* 得到过滤后的
  [
  E_{\text{neg,filtered}} = { (i,j)\in E_{\text{neg,raw}} \mid i,j\in V_{\text{pos}} }
  ]

**意义：**

* 只在“**已经有实验证据参与过互作**”的蛋白之间构造负样本，可以显著减少“未研究蛋白被当成真负”的风险；
* 与你提出的“**去除只涉及 neg 的 protein**”完全一致。

---

## 步骤 2：计算图上基本统计（degree / 邻接表 / hub）

在 (G_{\text{pos}}) 上做一次性统计（都是线性或亚线性复杂度）：

1. **度（degree）**

   * 对所有 (p \in V_{\text{pos}})，统计
     [
     d(p) = |{ q \mid (p,q) \in E_{\text{pos}} }|
     ]
   * 保存 degree 列表和全局分布（后面用来做 DDB 和 hub 划分）。

2. **邻接表**

   * 为每个蛋白 (p) 存一个邻接表 (N(p))，方便之后快速判断 “((p,q)) 是否已是正样本”。

3. **hub 定义**

   * 取 degree 的 80 或 90 百分位数，作为 hub 阈值 (T_{\text{hub}})；
   * 定义
     [
     \text{hub}(p) = [d(p) \ge T_{\text{hub}}]
     ]

> 这些统计全部离线一次性完成，之后采样都只用这些信息，满足你“快速、离线、不依赖外部模型”的要求。

---

## 步骤 3：构建 Degree Distribution Balanced (DDB) 候选负样本池

**核心思想：**
为每个正样本对 ((u,v)) 生成若干对“度和相似”的负样本对 ((u',v)) 或 ((u,v'))，保证正负样本整体的度分布尽量一致，避免模型学到“度越高越可能互作”的 shortcut。

### 3.1 按度分桶（bucketing）

1. 计算每个蛋白的度 (d(p))。

2. 定义若干度区间桶（例如按 log 刻度或等宽刻度）：

   * 桶 1：(d \in [1,2])
   * 桶 2：(d \in [3,4])
   * 桶 3：(d \in [5,8])
   * 桶 4：(d \in [9,16])
   * …（按你数据的 degree 分布自适应划分）

3. 对每个桶，记录属于该桶的蛋白列表。

> 文献中 DDB 的原始形式是“度和匹配”，这里用“度落在相同或相邻桶中”作为实施上的近似，更简单、更鲁棒。

### 3.2 为每个正样本对生成若干 DDB 负样本候选

对于每个正样本对 ((u,v))：

1. 计算 (u) 和 (v) 的度所在桶，记为 (b(u), b(v))。

2. 随机决定“**腐化哪一端**”（corrupt one end）：

   * 以 0.5 概率选择替换 (u)，生成负样本 ((u',v))；
   * 以 0.5 概率选择替换 (v)，生成负样本 ((u,v'))。

3. 若腐化 (u)，则：

   * 在“与 (b(u)) 相同或相邻的桶”中随机选一个蛋白 (u')，要求：

     * (u' \neq u)，
     * ((u', v) \notin E_{\text{pos}})（不是已知正互作），
     * （可选）((u',v)) 不重复之前已经为该 ((u,v)) 生成的 neg。

4. 同理腐化 (v) 时，在 (b(v)) 周围的桶中找 (v')，保证 ((u,v')) 不是正样本。

5. 为每个 ((u,v)) 生成 (K) 个这样的负样本候选（K=1–4 即可），组成 **DDB 负样本池 (C_{\text{ddb}})**。

这样，所有 DDB 负样本对 ((i,j)) 均满足：

* 两端都在 (V_{\text{pos}}) 中；
* 正负样本的度分布在统计意义上相近；
* 构造仅依赖当前 PPI 图，不需要任何外部模型或数据库。

## 步骤 4：用 2-hop 与 hub 构造“hard / easy”标签（完全图论）

在不引入任何外部信息的前提下，你仍然可以用 **局部拓扑结构** 给负样本标一个“难度”。

### 4.1 用 2-hop 结构定义“hard neg”

对于任意候选负样本对 ((i,j))：

* 如果存在第三个蛋白 (w) 使得：
  [
  (i,w) \in E_{\text{pos}} \quad\text{且}\quad (w,j) \in E_{\text{pos}}
  ]
  也就是 (i) 与 (j) 在图上是 **两跳可达的非邻居 (2-hop non-edge)**，
  则把 ((i,j)) 标记为：
  [
  \text{hard_2hop} = 1
  ]
* 实现上只需对每个候选对做一次简单的“邻居交集”检查：
  [
  N(i) \cap N(j) \neq \emptyset \Rightarrow \text{2-hop non-edge}
  ]
* 这是 PPI 图上常见的 motif：

  * 若两个蛋白共享大量邻居，它们在生物学上更可能互作；
  * 把这样的 pair 标成负样本，对模型来说确实“更难”。

### 4.2 用 hub 信息进一步加权难度

对每个候选对 ((i,j))，结合上一步的 2-hop 信息和 hub 标记：

* 若 (\text{hub}(i)) 或 (\text{hub}(j)) 为真，则：

  * 标记 `has_hub = 1`；
* 综合形成一个简单的难度标签：

  * **hard**：满足

    * `hard_2hop = 1`，或
    * `has_hub = 1`；
  * **default（中等难度）**：其他 DDB 负样本；

> 你可以不再单独定义“easy neg”，因为你已经从构造阶段删了大量明显不相关 protein（只在 neg 出现的蛋白），并且通过 DDB 保证了度相似性。
> 精简原则下，只要区分 **hard vs default** 两类就够了。

## 步骤 5：构建最终离线负样本库 & 1:1 采样策略

### 5.1 负样本库的结构

离线阶段，你最终得到的是一个“负样本索引表”，例如三列：

1. `protein_i, protein_j`：负样本 pair；
2. `is_hard`：布尔（或多类标签：hard / default）；
3. 可选一些辅助统计（如 degree 和、共有邻居数），但不再用于采样逻辑。

这个库可以按以下方式组织：

* 每个正样本 ((u,v)) 对应一个或多个负样本候选 ((u',v))/(u,v')；
* 或简单把所有候选负样本放在一个全局列表中，并分别维护：

  * `hard_neg_index`（只包含 is_hard=1 的行号）；
  * `default_neg_index`（只包含 is_hard=0 的行号）。

### 5.2 Pretrain 训练时的最简 1:1 采样规则

在 pretrain 阶段，每个 mini-batch 中：

1. 固定 **1:1 的正负比例**：

   * 假设你每个 batch 想用 `B_pos` 个正样本对；
   * 则从 neg 库中抽 `B_pos` 个 neg 对。

2. 在 neg 抽样时，按一个简单分层比例，比如：

   * `hard` 占 **30–40%**；
   * `default` 占 **60–70%**。

3. 训练循环中，可以选择：

   * 每个 epoch 重新随机匹配正样本与负样本（更丰富）；
   * 或者简单随机抽负样本，不刻意对齐到对应的正样本。

> 这样你就得到一个 **简洁但高质量** 的训练负样本策略：
>
> * 比原来 8:1 把计算量压到约 1/4；
> * 又绕开了“全随机 neg + 冷门蛋白”的质量坑；
> * 保留了 DDB 思路和硬负样本，从学界观点看是合理的。

---

## 步骤 6：为什么这是“最佳精简版”

在你给定的约束下（**仅用当前 dataset，完全离线，不连外部数据库 / 模型**），能做到的“前沿友好”大概就三件事：

1. **只在有正样本的蛋白子集上采 neg**

   * 减少“未观测=假负”的偏差。
2. **DDB 思路保持度分布平衡**

   * 阻止模型走 degree shortcut（Reim 等人指出这是序列 PPI 模型 plateau 的关键 bias 之一）。
3. **用 2-hop + hub 做少量 hard neg**

   * 完全基于图拓扑就能定义，计算代价可控，不引入外部知识，
   * 又能让模型在“拓扑上看起来像互作”的区域学到更细致的决策边界。

所有这些都可以一次性离线完成；实现层面无非是：

* 建图；
* 统计 degree & 邻接表；
* 分桶并采样；
* 做少量邻居交集判断。

不需要外部 web API，不需要结构预测，也不需要额外模型，是你现在能最快实现、同时仍然有理论与实践支撑的一套方案。
